Sækja viðbótina

🦊

Firefox

Fyrir Firefox 60+ með Manifest V2

Sækja fyrir Firefox

Uppsetning: Sæktu skrána, farðu í about:debugging → This Firefox → Load Temporary Add-on → Veldu manifest.json úr ZIP skránni

🌐

Chrome

Fyrir Chrome með Manifest V3

Sækja fyrir Chrome

Uppsetning: Sæktu skrána, farðu í chrome://extensions → Developer mode ON → Load unpacked → Veldu möppuna úr ZIP skránni

Hvernig virkar þetta?

1

Settu upp

Sæktu og settu upp viðbótina í vafrann þinn

2

Farðu á dv.is

Viðbótin virkar aðeins á www.dv.is og greiningarsíðum þeirra

3

Stilltu efnisflokka

Smelltu á viðbótartákn í tækjastikunni til að stilla hvað á að fela

4

Njóttu betri upplifunar

Óskylt efni er fólgið með litaðar blokka sem sýna hvað var falið

Búið til með gervigreind

Þessi viðbót var að öllu leyti búin til af Claude AI.

Höfundurinn hefur ekki skoðað eða staðfest kóðann. Allt frá viðbótinni sjálfri til þessarar vefsíðu var búið til af gervigreind.

Notaðu á eigin ábyrgð og traust.

Ef þú vilt skoða kóðann sjálf(ur) er hann aðgengilegur á GitHub.
